# Proyecto de Inversión: Alimento BARF Congelado en Neiva, Huila

Presentación web interactiva del proyecto académico de **Ingeniería Agroindustrial** de la **Universidad Surcolombiana**.

## Estructura del Proyecto
- `index.html`: Estructura semántica completa con las 16 secciones de la propuesta.
- `styles.css`: Hoja de estilos corporativa, paleta institucional verde/beige, diseño responsive y modo presentación.
- `script.js`: Interactividad del árbol de problemas, mockup de empaque, barra de progreso y navegación por teclado en modo exposición.

## Publicación en GitHub Pages
1. Sube los archivos `index.html`, `styles.css`, `script.js` y `README.md` a la raíz de tu repositorio en GitHub.
2. Ve a **Settings** -> **Pages** en tu repositorio.
3. En **Source**, selecciona `Deploy from a branch`, elige la rama `main` (o `master`) y la carpeta `/ (root)`, y guarda los cambios.
